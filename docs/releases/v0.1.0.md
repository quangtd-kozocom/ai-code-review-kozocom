# 🎉 v0.1.0 - Initial Release (MVP)

**Release Date:** 2024-12-21

> AI Code Reviewer MVP - Automated code review for GitHub Pull Requests using multiple AI agents.

---

## 🌟 Highlights

- **3 Specialized AI Agents** working in parallel
- **GitHub App Integration** with secure webhook handling
- **Background Processing** with Celery + Redis
- **Smart Aggregation** to reduce noise
- **Developer-friendly** quick start scripts

---

## ✨ Features

### 🤖 Multi-Agent Review System

Powered by LangGraph, our system uses 3 specialized agents running in parallel:

| Agent                 | Focus Areas                                                            |
| --------------------- | ---------------------------------------------------------------------- |
| 🔒 **Security Agent** | SQL injection, XSS, SSRF, hardcoded secrets, insecure configurations   |
| 🎨 **Style Agent**    | Naming conventions, code formatting, dead code, missing documentation  |
| 🧠 **Logic Agent**    | Null references, off-by-one errors, missing error handling, edge cases |

Each agent:

- Analyzes code diffs using LLM (GPT-4 or Claude)
- Provides confidence scores for findings
- Filters out low-confidence results (threshold: 0.7)

### 🔗 GitHub Integration

- **GitHub App Authentication**: JWT + Installation Tokens
- **Webhook Security**: HMAC-SHA256 signature verification
- **Supported Events**:
  - `pull_request.opened` - New PR created
  - `pull_request.synchronize` - New commits pushed
  - `pull_request.reopened` - PR reopened
- **Review Posting**: Comments appear directly on PR with severity badges

### ⚡ Async Processing

- **Celery** for background task processing
- **Redis** as message broker (supports Upstash cloud)
- **Retry Logic**: Max 3 retries with 60s delay
- **Non-blocking**: Webhook returns 200 OK immediately

### 🧠 Smart Aggregation

- **Deduplication**: Merges similar comments from different agents
- **Prioritization**: Sorts by severity (critical > warning > info > suggestion)
- **Limiting**: Caps comments per file to reduce noise
- **Confidence Filtering**: Only shows high-confidence findings

### 🔔 Notifications

- **Slack Integration** (optional)
- Review summary with severity counts
- Direct link to PR

## 🛠️ Developer Experience

### Quick Start Scripts

```bash
./scripts/start.sh          # Start API + Worker
./scripts/start.sh --ngrok  # Start with public tunnel
./scripts/start.sh --tmux   # Start in tmux (split panes)
./scripts/start.sh --dev    # Dev mode with hot-reload
./scripts/stop.sh           # Stop all services
```

### Makefile Commands

```bash
make dev      # Run FastAPI (dev mode)
make worker   # Start Celery worker
make test     # Run tests
make lint     # Check code style
make format   # Auto-format code
```
