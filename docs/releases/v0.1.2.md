# 🚀 v0.1.2 - Review Start Notification

**Release Date:** 2024-12-21

## 📋 Summary

This release adds an **acknowledgment notification** feature. When a PR is submitted for review, the system immediately posts a comment letting users know that the AI review is in progress, improving user experience.

## ✨ New Features

### Acknowledger Node

Added a new node at the beginning of the LangGraph workflow that posts an initial comment to the PR:

```
┌─────────────────────────────────────────────────────────────────┐
│                        REVIEW WORKFLOW                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  🆕 acknowledge ──► extract ──┬──► security ──┐                 │
│                               ├──► style ─────┼──► aggregate... │
│                               └──► logic ─────┘                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### How It Works

When a PR is created or updated:

1. **Immediate Feedback**: User sees a notification within seconds
2. **Clear Expectations**: Message explains what will be reviewed
3. **Better UX**: No more wondering if the reviewer is working

### Sample Notification

The following message is posted to the PR:

```markdown
🤖 **AI Code Review Started**

I'm analyzing your pull request. This may take a moment...

**What I'll check:**

- 🔒 Security vulnerabilities
- 🎨 Code style & best practices
- 🧠 Logic & potential bugs

I'll post my review shortly. Thanks for your patience! ⏳
```

## 🔄 Upgrade Notes

This is a **non-breaking** patch release. No configuration changes required.

To upgrade:

```bash
git pull origin main
# Restart your Celery workers to pick up the changes
./scripts/stop.sh
./scripts/start.sh
```

## 🐛 Notes

- If the acknowledgment fails (e.g., network error), the review continues without blocking
- Acknowledgment is posted as an issue comment, not a review comment
