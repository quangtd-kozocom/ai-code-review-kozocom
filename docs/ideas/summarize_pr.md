# 📋 Summarize PR

> Tóm tắt tất cả changes, purpose, và impact của PR

**Độ ưu tiên:** 🔴 Cao  
**Độ phức tạp:** Thấp  
**Tham khảo:** CodeRabbit PR Summary, GitHub Copilot

---

## 📋 Mô Tả

Tự động tạo summary cho PR bao gồm:

1. **What:** Những gì đã thay đổi
2. **Why:** Mục đích của changes
3. **Impact:** Ảnh hưởng đến codebase
4. **Review focus:** Những điểm cần chú ý khi review

---

## 🎯 Mục Tiêu

- **Primary:** Giúp reviewers nhanh chóng hiểu PR
- **Secondary:** Improve PR description quality
- **Tertiary:** Documentation cho future reference

---

## 💡 Command Usage

```markdown
# Generate summary

@reviewer summarize

# Update PR description with summary

@reviewer summarize --update-description
```

### 3. Create Handler

```python
# src/chat/handler.py

class SummarizeCommandHandler(BaseCommandHandler):
    """Generate comprehensive PR summary."""

    async def execute(self, ctx: CommandContext) -> str:
        try:
            # Gather PR data
            pr_details = await self.github.get_pr_details(
                ctx.owner, ctx.repo, ctx.pr_number
            )
            pr_files = await self.github.get_pr_files(
                ctx.owner, ctx.repo, ctx.pr_number
            )

            # Categorize files
            new_files = [f for f in pr_files if f["status"] == "added"]
            modified_files = [f for f in pr_files if f["status"] == "modified"]
            deleted_files = [f for f in pr_files if f["status"] == "removed"]

            # Generate summary with LLM
            prompt = SUMMARIZE_PROMPT.format(
                pr_title=pr_details["title"],
                pr_body=pr_details.get("body", ""),
                files_summary=self._format_files(pr_files),
                diff_content=self._format_diffs(pr_files[:5]),  # Limit
            )

            response = await self.llm.ainvoke(prompt)

            # Optionally update PR description
            if ctx.options.get("update_description"):
                await self._update_pr_description(ctx, response.content)

            return response.content

        except Exception as e:
            log.exception("Summary generation failed")
            return f"❌ Error: {e}"

    def _format_files(self, files: list[dict]) -> str:
        """Format file list for prompt."""
        lines = []
        for f in files:
            status_emoji = {
                "added": "🆕",
                "modified": "✏️",
                "removed": "🗑️",
            }.get(f["status"], "•")
            lines.append(f"{status_emoji} {f['filename']} (+{f['additions']}/-{f['deletions']})")
        return "\n".join(lines)

    async def _update_pr_description(self, ctx: CommandContext, summary: str):
        """Update PR body with generated summary."""
        await self.github.update_pr(
            ctx.owner, ctx.repo, ctx.pr_number,
            body=f"## AI Generated Summary\n\n{summary}\n\n---\n\n_Original description below_"
        )
```

### 4. Prompt Template

```python
# src/chat/prompts.py

SUMMARIZE_PROMPT = """You are a senior developer summarizing a Pull Request.

## PR Title
{pr_title}

## Original Description
{pr_body}

## Files Changed
{files_summary}

## Code Changes (Sample)
{diff_content}

## Task
Generate a comprehensive PR summary with:

1. **Purpose**: What is this PR trying to achieve? (1-2 sentences)

2. **Changes Overview**: Table of new/modified/deleted files

3. **Key Changes**: Bullet points of significant changes, grouped by feature/area

4. **Review Focus Areas**: What should reviewers pay attention to?
   - Security concerns
   - Performance implications
   - Edge cases

5. **Impact Analysis**:
   - Breaking changes?
   - Migration needed?
   - Documentation updates?

6. **Related**: Issue numbers, related PRs, dependencies

## Format
Use clean Markdown with emojis for visual hierarchy.
Be concise but comprehensive.
"""
```
